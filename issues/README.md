# Ошибки Ahrefs (Issues)

Эта папка предназначена для хранения отчетов об ошибках, найденных с помощью Ahrefs Site Explorer.

## Как использовать

Вы можете сохранять сюда информацию об ошибках в любом удобном формате:
- Экспорты из Ahrefs (CSV, Excel)
- Текстовые файлы (.txt, .md) с описанием проблем и ссылками
- JSON-файлы, если применимо

При добавлении новых файлов сюда, просто скажите мне (AI) проанализировать их. Я прочитаю файлы из этой папки и помогу шаг за шагом исправить каждую из найденных проблем!
